# АКиОС Лабораторная работа №1

Два shell-скрипта для обслуживания папки с логами: проверка заполнения, 
архивация самых старых файлов при превышении порога и автоматическое тестирование с жёстким ограничением размера через FUSE.

Всё работает в **user-space**, без прав root.

## Состав

| Файл | Назначение |
|---|---|
| `script1.sh` | Основной скрипт: проверяет заполнение, архивирует N самых старых файлов, удаляет их из исходной папки. |
| `script2.sh` | Тестовый скрипт: сам подготавливает окружение, монтирует ext4-образ через `fuse2fs`, прогоняет 5 тестов и убирает за собой. |

## Требования

- Linux или WSL2 (проверено на Ubuntu 24.04)
- `bash`
- Для тестов: `fuse2fs` и модуль `fuse`

Установка зависимостей (Ubuntu):

```bash
sudo apt install fuse2fs fuse
```

## Использование

### script1.sh

```
./script1.sh <путь_к_папке> [порог_в_процентах]
```

Примеры:

```bash
# Архивировать при заполнении более 70% (порог по умолчанию)
./script1.sh /var/log

# Свой порог — 85%
./script1.sh /home/user/log 85
```

Скрипт работает в цикле: пока заполнение превышает порог, он отбирает
самые старые файлы (по дате модификации), кладёт их в архив, удаляет из
папки и проверяет заполнение снова. Останавливается, когда всё в норме.

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BACKUP_DIR` | `<LOG_DIR>/../backup` | Куда складывать архивы. Папка создаётся автоматически. |
| `LAB1_MAX_COMPRESSION` | `0` | Если `1` — использовать lzma/xz вместо gzip. |

Пример:

```bash
BACKUP_DIR=/mnt/backups LAB1_MAX_COMPRESSION=1 ./script1.sh /var/log 70
```

Формат архива:

- по умолчанию — `archive_YYYYMMDD_HHMMSS.tar.gz`
- при `LAB1_MAX_COMPRESSION=1` — `archive_YYYYMMDD_HHMMSS.tar.xz`

### script2.sh

```
./script2.sh
```

Скрипт спросит желаемый размер папки (минимум 512M **не включительно**), создаст образ,
смонтирует его через `fuse2fs` и прогонит пять тестов. Результат — в
stdout, код возврата `0`, если все тесты прошли.

## Тестовые кейсы

| # | Что проверяется |
|---|---|
| 1 | Заполнение ниже порога — архивация не запускается, файлы остаются на месте, backup пуст. |
| 2 | Заполнение выше порога — старые файлы уходят в архив, свежий файл остаётся, backup не пуст. |
| 3 | Фильтрация по возрасту — в архив попадают именно самые старые файлы. |
| 4 | Валидация аргументов — неверный путь, нечисловой порог, порог вне диапазона, отсутствие аргументов. |
| 5 | `LAB1_MAX_COMPRESSION=1` — создаётся `.tar.xz`, архив читается. |
